# 阶段清单

这是测试客户端的完成度，不是正式版发布说明。没跑过的项保持未测。

| 阶段 | 状态 | 证据 |
| --- | --- | --- |
| 1. 音源契约和沙箱 | 部分完成 | Linux `SUMMARY failed=0`，并且实拉跟随了一次到 example.com 的重定向。API 21 隔离进程这次也跟随了 `httpbin.org` 的 302，RSA 向量比对通过，混合 DNS 被拒绝。Huibq 上游 503。QingLiang 未审未跑。音源兼容不算通过。 |
| 2. 平台适配器 | 部分完成 | 酷狗搜索有夹具和一次实拉。播放地址走 `m.kugou.com` 的 `playInfo`，只接受 HTTPS。这次 Linux 门拿到了 kugou.com 上的 HTTPS 音频。320k 哈希的上游码率仍是 128，不能当成音质切换已生效。酷我明文仍未实拉。QQ、网易、咪咕签名请求没有迁移。 |
| 3. 播放、服务、数据 | 部分完成 | 搜索到的酷狗曲目可以拿到 HTTPS 地址。API 21 上 `searchedKugouTrackCanPlay` 进入可播放状态。已审核脚本的 public-tone 仍在。没有 Room/DataStore，没有读旧数据。 |
| 4. 手机和车机界面 | 部分完成 | 播放页可搜酷狗并播放返回的 HTTPS。时间轴歌词按进度选行。API 21 上桌面歌词窗口能加上再去掉。车机 30%/70%/全屏仍是计划阈值。音质切换没有换成另一段音频。没有歌单页。 |
| 5. 集成和可安装包 | 部分完成 | 新 debug 包仍是独立 applicationId，minSdk 21。不是原版功能齐套。 |

- Huibq 的 503
- arm64 库在包里但没有被加载
- 模拟器上的播放页
