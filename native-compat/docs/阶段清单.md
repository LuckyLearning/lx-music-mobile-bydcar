# 阶段清单

这是测试客户端的完成度，不是正式版发布说明。没跑过的项保持未测。

| 阶段 | 状态 | 证据 |
| --- | --- | --- |
| 1. 音源契约和沙箱 | 部分完成 | Linux `SUMMARY failed=0`，并且实拉跟随了一次到 example.com 的重定向。API 21 隔离进程这次也跟随了 `httpbin.org` 的 302，RSA 向量比对通过，混合 DNS 被拒绝。Huibq 上游 503。QingLiang 未审未跑。音源兼容不算通过。 |
| 2. 平台适配器 | 部分完成 | 对照表在 `docs/音源对照.md`。播放地址按原版交给脚本的 `musicUrl`，请求形状有门测试。`playInfo` 不是原版 `getMusicUrl`，不再当作播放路径。320k 仍停在外部验证，没有绕过。酷我明文仍未实拉。QQ、网易、咪咕签名请求没有迁移。 |
| 3. 播放、服务、数据 | 部分完成 | 脚本返回的 HTTPS 地址可以播放，public-tone 仍在。搜索播放不再用别的接口顶上。没有 Room/DataStore，没有读旧数据。 |
| 4. 手机和车机界面 | 部分完成 | 打开已保存的本机歌单和收藏会开始播放。API 21 模拟器截图上能看见黄色桌面歌词「歌词测试行」。时间轴歌词按进度选行。在线歌单没有实拉。车机分屏仍是计划阈值。音质切换没有通过。 |
| 5. 集成和可安装包 | 部分完成 | 新 debug 包仍是独立 applicationId，minSdk 21。不是原版功能齐套。 |
