# 阶段清单

这是测试客户端的完成度，不是正式版发布说明。没跑过的项保持未测。

| 阶段 | 状态 | 证据 |
| --- | --- | --- |
| 1. 音源契约和沙箱 | 部分完成 | Linux `sh tools/run-gate.sh` 为 `SUMMARY failed=0`。隔离进程跑通官方 preload，并跑过一次 Huibq，上游 503。QingLiang 未审未跑。音源兼容不算通过。 |
| 2. 平台适配器 | 未完成 | 酷我搜索/歌单只有夹具和 URL 构造。kg/tx/wy/mg/xm 的搜索和歌单没有迁移。在线搜索没有接到界面。 |
| 3. 播放、服务、数据 | 部分完成 | 一个 Media3 1.8.0 `PlaybackService`。API 21 x86 上队列在控制器重连后还在，开机入口在自动播放关闭时不出声。数据在测试包自己的 SharedPreferences。没有 Room/DataStore，没有读旧数据。 |
| 4. 手机和车机界面 | 部分完成 | 播放页、歌词字号、车机收起规则、分开的开机自启和自动播放。API 21 模拟器看到手机竖屏；把模拟器改成 640×480 后看到「车机 70%」。不是比亚迪实测。没有逐行歌词、桌面歌词、歌单、音质、失败后的换源。 |
| 5. 集成和可安装包 | 部分完成 | debug 包 applicationId `cn.toside.music.mobile.nativegate.test`，合并清单 minSdk 21、禁止明文。能安装。不是原版功能齐套，也没有 release 签名。 |
