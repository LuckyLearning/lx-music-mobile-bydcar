# 阶段清单

这是测试客户端的完成度，不是正式版发布说明。没跑过的项保持未测。

| 阶段 | 状态 | 证据 |
| --- | --- | --- |
| 1. 音源契约和沙箱 | 部分完成 | Linux `sh tools/run-gate.sh` 为 `SUMMARY failed=0`。API 21 隔离进程补了 md5、AES-CBC 向量、二次取消抛错、formData 拒绝、51201 字歌词拒绝。重定向、重绑定和 RSA 仍只在 Linux/JVM。Huibq 上游 503。QingLiang 未审未跑。音源兼容不算通过。 |
| 2. 平台适配器 | 部分完成 | 酷狗搜索有夹具，并且这次 Linux 门对 `songsearch.kugou.com` 的 HTTPS 解析出了曲目。酷我搜索正文解析有夹具；明文连接器拒绝非 TLS，所以没有实拉。QQ、网易只有夹具解析，签名请求没有迁移。咪咕只有夹具解析。歌单签名没有迁移。 |
| 3. 播放、服务、数据 | 部分完成 | 一个 Media3 服务。已审核脚本只对 `public-tone` 返回一条公有 HTTPS 样本，API 21 上播放器进入可播放状态。酷狗搜索结果没有播放地址。没有 Room/DataStore，没有读旧数据。 |
| 4. 手机和车机界面 | 部分完成 | 播放页可搜酷狗、可播已审核样本，时间轴歌词有解析器。车机 30%/70%/全屏仍是计划阈值，只有模拟器上见过「车机 70%」。没有桌面歌词，没有按音质换流，没有歌单页。 |
| 5. 集成和可安装包 | 部分完成 | 新 debug 包仍是独立 applicationId，minSdk 21。不是原版功能齐套。 |

## 不能当成通过的项

- 用户手机上的诊断截图
- Huibq 的 503
- arm64 库在包里但没有被加载
- 模拟器上的播放页
- ExoPlayer 的焦点和拔耳机代码
