# 阶段清单

这是测试客户端的完成度，不是正式版发布说明。没跑过的项保持未测。

| 阶段 | 状态 | 证据 |
| --- | --- | --- |
| 1. 音源契约和沙箱 | 部分完成 | Linux `SUMMARY failed=0`，并且实拉跟随了一次到 example.com 的重定向。API 21 隔离进程这次也跟随了 `httpbin.org` 的 302，RSA 向量比对通过，混合 DNS 被拒绝。Huibq 上游 503。QingLiang 未审未跑。音源兼容不算通过。 |
| 2. 平台适配器 | 部分完成 | 酷狗、QQ、网易、咪咕、酷我搜索都按原版请求打过一次。同一份正文上，原版解析和移植解析的曲目数一致：酷狗 10、QQ 10、网易 10、咪咕 13、酷我 5。签名与原版函数一致。歌单行解析有夹具，在线歌单页还没接上。 |
| 3. 播放、服务、数据 | 部分完成 | API 21 隔离进程跑了已审的轻量音源 2.1.0。它按搜索到的 QQ 歌曲返回 `isure6.stream.qqmusic.qq.com` 的 HTTPS 地址，Media3 进入可播放状态。脚本没有放进仓库。public-tone 仍只是样本。没有 Room/DataStore，没有读旧数据。 |
| 4. 手机和车机界面 | 部分完成 | 打开已保存的本机歌单和收藏会开始播放。API 21 模拟器截图上能看见黄色桌面歌词「歌词测试行」。时间轴歌词按进度选行。在线歌单没有实拉。车机分屏仍是计划阈值。音质切换没有通过。 |
| 5. 集成和可安装包 | 部分完成 | 新 debug 包仍是独立 applicationId，minSdk 21。不是原版功能齐套。 |

## 不能当成通过的项

- Huibq 的 503
- arm64 库在包里但没有被加载
- 模拟器上的播放页
- ExoPlayer 的焦点和拔耳机代码
