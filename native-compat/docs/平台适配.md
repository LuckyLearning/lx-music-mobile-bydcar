# 平台适配矩阵

酷我搜索和歌单目前只有不联网的解析与 URL 构造，外加固定样本。这还不是已迁移的平台 SDK。`getMusicUrl` 仍由用户脚本负责。其它平台没有移植。没有对酷我服务器做线上对照。

| 能力 | 旧代码 | 这次 | 验证 |
|---|---|---|---|
| 酷我搜索 URL | `kw/musicSearch.js` `musicSearch` | `KwCatalog.searchUrl` | 单测核对路径和分页。默认策略拒绝这段明文 URL |
| 酷我搜索结果 | `handleResult`：音质、歌名实体、歌手 `&`、时长 | `KwCatalog.parseSearchList` | 固定样本。缺 `N_MINFO` 时整表失败，和旧代码一样 |
| 酷我歌单列表 URL | `songList.js` `getListUrl` | `playlistListUrl` | 单测。不发请求 |
| 酷我歌单详情 URL | `getListDetailUrl` | `playlistDetailUrl` | 单测。id 必须是数字 |
| 酷我标签 | `filterInfoHotTag`、`filterTagInfo` | `hotTags`、`tagGroups` | 固定样本 |
| 酷我歌词、评论、图片、直链 | 旧模块仍在 RN 工程 | 未移植 | 未测 |
| kg / tx / wy / mg / xm 搜索和歌单 | `src/utils/musicSdk` | 未移植 | 未测 |
| 用户脚本 musicUrl | preload | 合成门已覆盖 | 不是平台适配器 |

明文：酷我这些旧 URL 是 `http://search.kuwo.cn` 等。播放器或适配器要连它们，必须由调用方把该主机放进明确的明文名单。脚本改不了这个名单。测试包的网络安全配置关闭了全局明文。
