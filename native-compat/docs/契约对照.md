# 宿主契约对照

提取基准是 `ad77216fdb3d195072cdddbe687006715971ecad`。下表区分「脚本可见行为」和「新宿主」。通过只表示有对应测试，不表示旧版 APK 已并排运行。

| 契约 | 旧实现 | 这次的结果 |
|---|---|---|
| 身份 | preload 固定 `lx.version='2.0.0'`、`lx.env='mobile'` | 沙箱读取到同样的值。手机和车机模式以后都不能改成 desktop |
| 初始化 | `lx_setup` 后脚本 `on(request)`，再 `send(inited)`。重复初始化被拒绝 | 顺序测试通过。`xm` 不进入 `allSources`。非 music 类型被跳过 |
| 在线动作 | `kw/kg/tx/wy/mg` 只有 `musicUrl`。音质 `128k/320k/flac/flac24bit` 取交集 | 与 preload 过滤结果一致 |
| 本地动作 | `musicUrl`、`lyric`、`pic`，没有在线音质列表 | 一致 |
| 搜索和歌单 | `src/utils/musicSdk/index.js` 注册 `kw/kg/tx/wy/mg` 并导出 `searchMusic`。`xm` 被 import，但不在 `sources` 数组里 | 只做了源码断言。Kotlin 适配器还没有 |
| 业务超时 | `userApi/index.ts` 外层 20 秒。切源时未完成请求以 `request failed` 失败。`canceleFn` 是空函数 | `BusinessGate` 用假时钟覆盖成功、超时、迟到结果和切源。没有把空取消照抄进新门 |
| HTTP | `request.js` 默认 13 秒，上限 60 秒。POST form 编码；`formData` 分支遍历的是 `form` | form 和 JSON 与旧整形一致。`formData` 直接拒绝。GET 带 body 拒绝，避免夹带 |
| 传输 | RN `fetch`，取消走 AbortController | 父进程 HTTPS。先解析，只连接已经判定为公网的字面地址，重定向每跳重做。`example.com` 实请求通过。私网、回环、CGNAT、链路本地、文档地址、组播在单测里被拒绝 |
| 明文 HTTP | preload 的 `musicUrl`/`pic` 允许 `http:` 和 `https:` | 脚本字符串层仍允许。播放准入和 socket 层拒绝明文 |
| 歌词 | 正文长度 `> 51200` 失败；翻译/音译 `< 5120`；lxlyric `< 8192` | 用 5119、5120、8192 测过 |
| 定时器 | `setTimeout` 把 id 交给原生；`clearTimeout` 不取消原生定时器 | 清掉的回调不再运行，原生回调仍会送到 |
| 重复取消 | 取消函数把 `request` 置空，第二次调用抛错 | preload 行为仍在，测试锁住 |
| Buffer | `bytesToString` 只覆盖 1–3 字节 UTF-8 | 4 字节序列得到 `U+07D9` 和 `U+2000`。没有改成标准 UTF-8 |
| Base64 / MD5 | Java `Base64.NO_WRAP`、URLDecoder 后 MD5、小写十六进制。失败返回空串 | 与 JDK Base64 和独立 MD5 向量一致，含 `+` 和坏的 `%` |
| AES | preload 把 `aes-128-cbc` 编成 `AES/CBC/PKCS7Padding`，把 `aes-128-ecb` 编成模式名 `AES` 且 iv 为空。iv 截断或补零到 16 字节 | JDK 上 PKCS7 名称落到 PKCS5，密文与独立 Cipher 一致。带 iv 的 `AES` 模式返回空串，和 Java 在 ECB 上再塞 IvParameterSpec 会失败一样 |
| RSA | 公钥加密，preload 使用 `RSA/ECB/NoPadding` | 2048 位临时密钥的 NoPadding 和 OAEP 能被私钥解回。不使用固定密钥，也不把这套算法用于新的应用加密 |
| 二进制 HTTP | RN 把 blob 转成 Buffer，再 JSON 跨桥 | 脚本看到的是 base64 对象。字节在宿主侧保持，对象类型不相同 |
| 动态代码 | preload 禁用 `eval` 和 `Function` | 沙箱里两者都抛错。`require/process/Java/std/os/fetch` 不存在 |
| 配额 | 工具参数 1,048,576 字符；native JSON 2,097,152 字符 | 超限抛出 `InputQuotaError`，不会变成空的加密结果。JS 堆 32MiB，单次 CPU 片约 2 秒，会话墙钟由父子两边同时限制 |
